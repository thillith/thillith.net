>This server & I'ts services:
This is an Ubuntu server on a Pi 5 that I use for most my homelab needs, there is more info in the specs here /aboutme but
this part is mosty about services, I have deployed: Navidrome, Jellyfin, Opemmtg, 2 Minecarft servers, Ngenx (for proxying) and ofc a apache2 Websrver.

>Navidrome; is an all-in-one music server software built on the Open Subsonic API. Navidrome has a web UI but can also be used with any opensubsonic client such as feishin. My favourite feature is Last.fm scrobbaling, this keeps track of my music listens and they have a good API that I've made a small UI with to show my recent listens at /music.
I love Navidrome as it gives me easy ubiquitous access to the music I have digitally, and seamless music tracking.

>Jellyfin; is an all-in-one video & music streaming service, I only use it for films and shows. Using a custom verson of FFmpeg by Jellyfin it comes built in with transcoding and good presets for such, it runs just fine on my pi alongside the other running containers.

>OpenMTG; is a Magic The Gathering card tracking and deck building software. It features: automatic price syncing, card image fetching, deck statistcs and multi accounting. Openmtg fetches from a community mantained db; Scryfall. I really like running this one because I love keeping track of my things and data and this does it really well.

>Docker; is a light wight, feature rich, easy to use containerisation software that I use for partitioning and controling running software. Containers are good for security as are usually as hard to escape as a hypervisor, they emulate the file system but they do still use the host kernel.
